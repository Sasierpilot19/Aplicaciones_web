## APLICACIONES WEB 🌐

### Internet y la web no son lo mismo

Para construir aplicaciones, primero devemos entender la diferencia fundamental entre la carretera fisica y los vehiculos que circulan por ella.

```
El Internet (La autopista) 🚩🛣️
```
La infraestructura fisica global, cables submarinos, routers y redes interconectadas. Es el asfalto por donde viaja la informacion bruta 

```
La web (Los vehiculos) 🚗🛻🚙
```
El servicio y las aplicaciones web.
Paginas, sistemas, y plataformas.
Utilizan un idioma comun para viajar sobre la autopista y llegar a su destino.

---
### El Modelo Cliente-Servidor 
Toda aplicacion web funcional depende de una conversacion constante entre quien pide y quien entrega.

```
El comensal (cliente) 👨🏻‍🦰
```
Tu navegador web (Chrome, edge, Safari) Sabe exactamente lo que el usuario quiere ver, pero no tiene los ingredientes para cocinarlo.

```
El mesero (Protocolo HTTP/HTTPS) 🤵🏻‍♂️
```
El mensajero de la web toma tu pedido

```
La cocina 🧑🏻‍🍳
```
Recibe la orden, ejecuta las reglas del negocio y decide como procesar la peticion.

```
La alacena (Base de Datos) 🧺
```
Almacena y extrae la informacion exacta necesaria para esta orden especifica.

```
El platillo (Respuesta) 🍝
```
El resultado final (codigo HTML, datos JSON) que se envia de vuelta al comensal para que consuma.

---
## Anatomia de una Aplicacion Web: EL TEATRO 🎭🎪

Todo  sistema de software se divide entre **la experiencia que vive el espectador** y **la maquina** que hace que la obra sea posible

### El Escenario: Front-End 🖼️

```
HTML (El guion  / Estructura)
```
Define que se dice y en que posicion del escenario se colocan los actores(texto, imagenes, botones)

```
CSS (El vestuario / Escenografia )
```
Define como se ven las cosas. Colores, tipografias, diseño responsivo y estetica visual.

```
JavaScript (La Accion)
```
Define el movimiento. La interactividad los efectos especiales y la reaccion al aplauso del publico en tiempo real.

### Bambalinas : Back-End ⚙️
```
Logica del Negocio
```
Las reglas invisibles (Eje. ¿Cuantos boletos quedan disponibles? ¿El usuario tiene permiso para entrar?).

```
Seguridad y Sesiones
```
Autenticacion de usuarios y proteccion estricta de la informacion personal

```
Gestion de Bases de Datos
```
El archivo historico integral de todas las operaciones, obras y usuarios.


| Atributo | Front-End |Back-End|
|---|---|---|
|El rol principal|La experiencia (El escenario)| El Cerebro (La maquinaria)|
|Lenguajes Clave|HTML,CSS,JS|dawdawd|
